# Alacritty Configuration

This directory contains the user-specific configuration for the Alacritty terminal emulator.

## Key Files

- **`alacritty.toml`**: The main configuration file for Alacritty. This file contains settings for a wide variety of things, including:
    - Font size and family
    - Color scheme
    - Keyboard shortcuts
    - Window appearance and behavior
    - Shell configuration
    - Mouse bindings

## Usage

This directory is read by Alacritty on startup. Any changes to `alacritty.toml` will be applied the next time Alacritty is started.
